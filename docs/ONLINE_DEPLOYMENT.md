# Déploiement en ligne

Ce dépôt prépare PostgreSQL, API, web et Caddy, mais aucun déploiement n’est encore autorisé. Copier un exemple d’environnement vers un gestionnaire de secrets, choisir un domaine, appliquer les migrations, puis démarrer les services. Ne jamais publier le port PostgreSQL et ne jamais committer `.env.production`.
